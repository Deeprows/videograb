# VideoGrab

Download videos from YouTube, TikTok, Facebook, X (Twitter) and Dailymotion by pasting a link,
sharing it to the app, or tapping Download while browsing inside the app.

- Paste / share / copy a link -> preview with thumbnail, title, duration and real quality options + sizes
- Browser tab with login support (cookies are reused for private / login-only videos)
- Background downloads with pause, resume and retry; saved to Movies/VideoGrab and Music/VideoGrab
- yt-dlp engine refreshes itself every ~12h and repairs itself when a site changes

Build: `gradle assembleDebug` (JDK 17, Android SDK 34) or push to GitHub and use the included workflow.
